## 2024-05-24 - Cross-Site Scripting (XSS) via DOM-based escape function
**Vulnerability:** The application's `escape` function (`Finora.escape`) in `assets/js/app.js` used a DOM-based approach to escape HTML entities: `const el=document.createElement('div');el.textContent=value;return el.innerHTML;`. This approach fails to escape quotes (`"` and `'`), making the application vulnerable to attribute-based Cross-Site Scripting (XSS) when the escaped output is used within HTML attributes.
**Learning:** Using the browser's DOM (`textContent` -> `innerHTML`) to sanitize data is dangerous because it is context-unaware and does not escape all potentially harmful characters. It only escapes characters necessary for valid HTML content (like `<` and `>`), leaving quotes intact which can break out of attributes. The performance is also worse due to DOM thrashing.
**Prevention:** Always use regex-based, comprehensive string replacement for sanitizing HTML output, replacing `&`, `<`, `>`, `"`, and `'` with their respective HTML entities, especially when interpolating values into raw HTML strings, which is a pattern heavily used in this codebase.
